=========================================================
      Google SEO CMS 新系统 - 终极保姆级使用说明书
=========================================================
这套系统是一套现代化的 SEO 批量生成系统。相比于老版的寄生虫（如 mb.txt 时代的隐藏字符），它生成的页面对谷歌更加友好，自带极速静态化、锚文本内链轮盘、本地图片化、多模板随机防站群以及智能蜘蛛判断跳转功能。

【核心理念：与老程序完美隔离的“寄生目录”玩法】
为了防止新老程序代码冲突（混在一起导致网站崩溃），新系统采用了高度内聚的架构。
你只需要在老网站的根目录建一个独立文件夹（如 `googleseo`），把本系统放进去，它就能独立运作，像“寄生树”一样疯狂吸取谷歌流量，绝不影响老网站！

【核心目录结构说明】
- admin/        : 后台管理端（含生成引擎 generate.php 和 10套SEO极品模板 templates/）
- data/         : 数据中心（你的关键词库 txt、数据库 db，以及统计跳转代码 global_script.txt）
- spider/       : 爬虫中心（自动化抓取文章、下载图片并生成 sitemap）
- public/       : 财富中心（最终生成的所有静态 HTML 网页和图片都在这里，用来给谷歌抓取）

---------------------------------------------------------
第一步：部署与基础配置 (防混淆隔离)
---------------------------------------------------------
1. 在你的老网站根目录里，新建一个纯英文文件夹，比如叫 `googleseo`。
2. 将 `Google_SEO_CMS_新系统` 里面的所有文件放进 `googleseo` 里。
3. 打开 `admin/config.php`，修改第 8 行的域名（指向你的新目录）：
   define('SITE_URL', 'https://你的老网站.com/googleseo/public');
4. 打开 `spider/generate_sitemap.py`，修改第 19 行的域名：
   SITE_URL = "https://你的老网站.com/googleseo/public"

---------------------------------------------------------
第二步：导入你的海量 SEO 关键词
---------------------------------------------------------
1. 打开 `data/keywords_vi.txt`（越南语），把你要做排名的成千上万个关键词粘贴进去（一行一个）。
2. 如果有自定义标题和描述，填入 `titles_vi.txt` 和 `descriptions_vi.txt`。
3. 系统的“确定性哈希算法”会将采集的文章与这些关键词永久绑定，不会因为重复生成而乱跳。

---------------------------------------------------------
第三步：配置智能跳转与统计代码 (核心收割)
---------------------------------------------------------
1. 打开 `data/global_script.txt`。
2. 在上半部分粘贴你的 Google Analytics 统计代码。
3. 在下半部分，去掉 `window.location.href` 前面的注释 `//`，并把网址换成你要引流的最终落地页（如你的 Zalo 或主站）。
4. 这里的 JS 代码自带 Cloaking (斗篷法)：谷歌蜘蛛来抓取时看到的是纯正的新闻，只有真实的手机/电脑访客搜索进来时，才会瞬间跳转到你的落地页！

---------------------------------------------------------
第四步：启动自动采集与图片下载
---------------------------------------------------------
1. 在宝塔面板的“计划任务”里，新建一个“Shell脚本”，每 1-2 小时执行一次：
   cd /www/wwwroot/你的老网站.com/googleseo/spider/
   python3 spider.py
2. 爬虫不仅会抓取文章，还会**自动破解防盗链，将原网站的图片下载到 public/uploads/ 里**。
3. 抓取完毕后，爬虫会尝试更新已有生成清单的 Sitemap；新采集但尚未生成的文章不会进入 Sitemap。

---------------------------------------------------------
第五步：一键生成十万静态霸屏页面
---------------------------------------------------------
1. 在浏览器访问后台：
   https://你的老网站.com/googleseo/admin/index.php
2. 点击页面上的大绿按钮：“⚡ 一键生成静态网站”。
3. 系统会瞬间在 `public/` 文件夹里，生成极速 HTML 静态页。
4. 【黑科技】系统会**自动从 10 套高端模板中随机抽取**，并且在文章底部**自动生成带有目标关键词的锚文本内链轮盘**。

---------------------------------------------------------
第六步：向谷歌提交 Sitemap
---------------------------------------------------------
1. 去 Google Search Console (GSC) 提交你的 Sitemap。
2. Sitemap 在新系统的 public 目录内。本服务器地址是：
   http://facegfx.com/yuenan/googleseo/public/sitemap.xml
   以 admin/config.php 的 SITE_URL 为准；Python 从生成清单读取相同域名，不再推算未生成的链接。

---------------------------------------------------------
相关新闻标题与目标页面对应关系修复
---------------------------------------------------------
1. 上传覆盖 admin/generate.php、admin/config.php、spider/generate_sitemap.py。
   config.php 若有自己的其他设置，请保留，只将 vi 的 title_rule 设置成 '{article_title}'。
2. 不需要删除数据库，也不需要重新采集。打开后台，重新点击一键生成。
3. 新文件名为“关键词-slug-文章ID.html”，例如 plants-12.html。
   ID 防止不同新闻共用关键词时互相覆盖。旧链接不自动迁移，旧文件不自动删除。
4. 相关推荐显示目标新闻的采集标题；目标页面 H1 显示同一采集标题。
   越南语页面的 title 也使用采集标题；keywords 和 description 仍调用你的 TXT 库。
   titles_vi.txt 保留，但当前 vi 标题规则不使用它；其他语言配置不改变。
5. data/generated_pages.json 是自动生成的文件映射清单，不要手动编辑。
   PHP 完成生成时自动更新 public/sitemap.xml，Python 仅同步清单中确实存在的文件。
6. 验证请从本次生成日志里的新链接进入，刷新后点击相关推荐，
   核对推荐文字、目标页 H1 和正文是不是同一条新闻。不要用旧的无 ID 链接测试。
7. 本地 .dbg 目录是测试环境，不需要上传。不会修改外面的老程序。

【相关文章、其他新闻文章部分标题无法点击】
1. 覆盖 spider/spider.py 和 admin/generate.php，不删除数据库。
2. 在宝塔执行新版采集任务。它会从已有新闻正文中的原始链接，
   补采“相关文章”和“其他新闻文章”，不再只采集首页新闻。
3. 每站最多尝试 sources.json 中 max_articles 指定的篇数。日志 pending 大于 0 时，
   等本次任务结束后再运行，或让下一次计划任务继续；不要同时启动多个任务。
4. 补采完成后，后台重新生成。已入库新闻的标题和图片会指向对应本地页面。
5. 原站无法访问、解析失败或尚未采集的新闻仍不能点击。
   不会把它的标题随意链接到另一篇新闻。查看采集失败日志后再处理。

【底部友情链接数量】
每页随机选取 200-1000 个同语言文章链接，锚文本仍使用目标页关键词。
排除当前文章，同一目标 URL 不重复；不同文章可能使用相同关键词文字。
如果同语言文章只有 59 篇，每页最多显示 58 条，不重复填充到 200 条。
正文相关推荐仍保留 3-5 条，不受底部数量设置影响。
修改后覆盖 admin/generate.php 并重新生成即可。
大量底部内链会增加页面体积，不保证提升搜索排名。

【多个网站采集配置】
1. 服务器覆盖 spider/spider.py，并上传新增的 spider/sources.json，两者缺一不可。
2. 当前启用三个越南语来源，依次运行：
   nongnghiephuuco.vn：首页及历史 Sitemap，单次最多尝试 500 篇，间隔 2 秒；
   sfarm.vn：/blog/ 及历史分页，每次发现 10 页，最多尝试 300 篇，间隔 3 秒；
   dantri.com.vn：首页及历史 Sitemap，单次最多尝试 500 篇，间隔 3 秒。
   图片请求同样采用本站配置的间隔，因此含大量图片时运行时间较长。
3. 以后所有网站配置修改 spider/sources.json，不再修改 spider.py 顶部的旧单站变量。
   enabled=false 停用某站；language 控制该来源语言；list_url 是列表页；
   allowed_hosts 限制采集域名；三个 selector 分别匹配链接、标题、正文；
   article_path_pattern 是新闻路径规则；max_articles 和 request_delay 控制数量、间隔。
   sitemap_urls 指定历史文章入口，sitemap_files_per_run 控制每次扫描数量。
   list_page_template 和 list_pages_per_run 控制分页发现。
   待采集链接和分页进度保存在同一个数据库中，后续任务继续处理。
   单次上限指尝试量，不保证全部成功；连续失败 3 次的链接暂时不再自动重试。
   JSON 必须使用双引号，不能加注释或末尾逗号。
4. 宝塔仍保留一个 Shell 任务，脚本：
   /usr/bin/flock -n -E 75 /www/wwwroot/facegfx.com/yuenan/googleseo/data/spider.lock /usr/bin/python3 -u /www/wwwroot/facegfx.com/yuenan/googleseo/spider/spider.py
   status=$?
   if [ "$status" -eq 75 ]; then echo "已有采集任务运行，本次跳过，请等待。"; exit 0; fi
   exit "$status"
   flock 避免任务重复启动；确认服务器存在 /usr/bin/flock 和 /usr/bin/python3。
   不要给三个来源分别建立同时执行的任务。
   不要连续点击执行；Successful 只是宝塔包装脚本记录，不是采集成功数。
   以每站 attempted/saved/pending 和最终“采集任务执行完毕”为准。
   1300 篇含图片的任务可能运行数小时，上限不是每小时保证完成的数量。
5. 不删除数据库。采集结束后，在后台重新生成页面。
   三站文章统一存入 data/seo_data.db，图片存入 public/uploads/。
6. 网站改版可能导致选择器失效；403、429、验证码应停止频繁请求，不绕过访问限制。
   转载文章前确认版权授权和网站使用条款。

【模板固定与首页保留】
1. 覆盖 admin/generate.php，不删除 public 页面或数据库。
2. 新文章首次生成时分配模板，保存到 data/template_bindings.json。
   重新生成和新增模板不会重新随机分配已绑定文章。
   备份系统时同时备份此文件；不要删除或覆盖为空文件。
3. 对已有页面尝试通过内联 CSS 匹配原模板，匹配不了会停止提示，不擅自更换。
   已绑定模板若被删除会报错要求恢复；修改该模板文件的 CSS 会影响使用它的页面。
4. 已有 public/index.html 完整保留，新增新闻不替换首页文章。
   首页的相关推荐和其他内容也不会自动更新。只有没有首页时才创建首页。
   网站原根目录的首页不受此脚本影响。
5. 本次只固定模板选择和保留首页，不是永久固定普通文章的 URL、TDK。
   关键词、标题、描述库或规则改变后，普通文章 URL/TDK 仍可能变化。
   普通文章的相关推荐和友情链接仍会在重新生成时更新。

大功告成！躺等收录和流量！
